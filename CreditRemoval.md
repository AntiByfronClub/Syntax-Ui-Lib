# Credit Removal

If you need a version of Syntax UI Lib without the required credit check, there are two ways to get one.

## Request a fork

You can request a fork of the repository with the credit requirement removed. Open an issue or contact me with your GitHub username and what you need changed.

## Message me for a copy

You can also message me directly and ask for a copy of the Luau source without the credit requirement. Please explain what you plan to use it for so I can send you the right version.

Those are the only ways to get the credit requirement removed. Please do not try to bypass or remove it from a downloaded copy without asking first.
